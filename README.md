# Relay Rider Institutional Research Beta Landing Page

Standalone, StackBlitz-ready landing page for Relay Rider, an institution-sponsored commuter research beta for planned-route interest, candidate Access Points, EV/hybrid participation signals, and Rule 2202-adjacent data support.

## Product posture

- Institution-sponsored commuter-program research beta
- Commuter and EV/hybrid participant interest intake
- Planned-route / route-interest signals
- Candidate Access Points only; not approved service locations
- Green Wallet means institution-sponsored Green Route Credit, not cash, stored value, payment, reimbursement, reservation, or live charging session settlement
- Administrative review before any future program decision
- No live payments, booking, dispatch, guaranteed transportation, or active program claims

## Run

```bash
npm install
npm start
```
